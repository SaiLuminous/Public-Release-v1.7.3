Submit this single file as:
mods/application-windows-no-min-size.wh.cpp

Before a stable release, live-test enable/disable, Explorer with no folder
windows, minimized windows, manual-close waiting, and File Pilot with the
override off and on. Syntax checks are not runtime validation.

Suggested PR title:
Add Application Windows: No Minimum Size

Suggested description:
Extends Anixx's Explorer No Minimum Window Size approach to eligible application
windows. Includes an opt-in, build-checked File Pilot 0.8.5 override and waits
for affected windows to be closed or enlarged before unloading.
Both x86 and x86-64 source syntax checks pass. Runtime validation remains pending.

Submission requirements:
https://github.com/ramensoftware/windhawk-mods#submitting-a-new-mod

Diagnostic build: unload phases and window dimensions are logged as UTF-16 to %TEMP%\Windhawk-NoMinSize-<PID>.log. Window titles and contents are not recorded. This version diagnoses the remaining wait; it is not a verified fix.
